# AirBnB
Airbnb is a modern web-based hosting and booking platform designed to make finding, listing, and managing accommodations simple and effortless. The project provides a user-friendly experience for both guests looking for the perfect place to stay and hosts who want to list and manage their properties online.

Key Frames

User Authentication: Users can sign up and log in securely to access the app's features.

Property Listing: Users can add, edit, and delete their property listings.

Booking System: Users can search for available properties and make bookings.

Booking History: Users can view their booking history.
